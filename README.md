# Black Bean — лендинг кофейни

Одностраничный сайт спешелти-кофейни с собственной обжаркой.
Собран с нуля на Vite + React + TypeScript + Tailwind CSS v4.

## Запуск

```bash
npm install
npm run dev      # http://127.0.0.1:5173/
npm run build    # сборка в dist/
npm run preview  # локальный просмотр сборки
```

## Дизайн-система

Токены живут в `src/index.css` (CSS-first конфигурация Tailwind v4, блок `@theme`).

| Роль | Значение | Применение |
| --- | --- | --- |
| Фон страницы | `#F9F5F0` | фон секций |
| Поверхность карточки | `#FDFBF7` | секция «О кофейне» |
| Основной текст | `#2C1810` | заголовки, основной текст |
| Вторичный текст | `#5E554A` | описания, подзаголовки |
| Приглушённый текст | `#7B7266` | мета, подписи, лоты |
| Акцент (заливка) | `#D4A574` | кнопки, точки лотов |
| Акцент (текст/инк) | `#8A5A2E` | мелкие маркеры, иконка логотипа |

`#D4A574` как текст на светлом фоне не проходит контраст 4.5:1, поэтому для текстового
применения используется затемнённый `#8A5A2E` (5.4:1), а `#D4A574` работает заливкой
с тёмным текстом `#2C1810` (7.6:1).

Типографика: **Inter** для интерфейса и цифр, **Instrument Serif** — только крупные
заголовки и логотип. Веса 400 и 500, никаких 700–900. Все числа — `tabular-nums`
в одном формате.

## Решения

- **Без анимационной библиотеки.** Появления по скролле реализованы через
  `IntersectionObserver` + CSS-переходы (`src/hooks/useReveal.ts`). Один вход,
  подъём на 12px, одна кривая `cubic-bezier(0.22, 1, 0.36, 1)`. Учитывается
  `prefers-reduced-motion`.
- **Mobile-first.** На мобильных hero складывается в колонку: текст, действия,
  затем фотография. На десктопе — сцена во весь экран, заголовок лежит на
  светлой части кадра.
- **Фирменная деталь.** Дата обжарки партии зерна (`обжарено 14.11`) под каждым
  напитком — меняется вместе с сезонным лотом.
- **Изображения сгенерированы** (Matrix image model) и вручную кадрированы:
  сервис штампует водяной знак в нижний правый угол, `scripts/crop-images.ps1`
  срезает нижнюю полосу. Оригиналы сохранены в `public/images/source/`.

## Превью

```bash
npm run dev
node scripts/preview.mjs http://127.0.0.1:5173/ ./preview
```

Скрипт снимает первый экран и страницу целиком в 1440×900 и 390×844, а также
проверяет горизонтальный скролл и ошибки консоли.
